# 🎥 DevHub Meet

A full-stack video conferencing web application designed for seamless online meetings, real-time communication, and collaborative sessions.

## ✨ Overview

DevHub Meet is a web-based video conferencing platform that allows users to create or join meeting rooms and communicate through their browser.

The application provides a simple meeting experience with real-time video/audio communication and screen sharing, making it suitable for online meetings, discussions, interviews, and collaborative sessions.

## 🚀 Features

- 🔐 User authentication
- 🎥 Real-time video conferencing
- 🎙️ Audio communication
- 🖥️ Screen sharing
- 🏠 Create and join meeting rooms
- 💬 Real-time communication
- 📜 Meeting history
- 📱 Responsive user interface
- ⚡ React-based frontend
- 🔗 Backend API integration
